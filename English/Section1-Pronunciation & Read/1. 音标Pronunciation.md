
# 一. **元音 (20个)**

声音响亮，气流不受阻碍，是单词发音的核心。

##  1. 单元音 12 个 (Pure Vowels / Monophthongs)

|         | 前元音 (舌位靠前)   | 中元音 (舌位居中) | 后元音  (舌位靠后)      |
| ------- | ------------ | ---------- | ---------------- |
| **长元音** | /iː/         | /ɜ:/       | /u:/, /ɔ:/, /ɑ:/ |
| **短元音** | /ɪ/，/e/， /æ/ | /ə/, /ʌ/   | /ʊ/,/ɒ/          |
**:** 被称为长音符号
这个符号是区分单词意义的关键，因为许多单词仅通过元音的长短来区别。

🔍 主要作用：区分词义
长音符号 : 的存在，使得我们能够准确区分一些拼写相似但含义完全不同的单词。例如：
sheep /ʃiːp/ (绵羊) vs. ship /ʃɪp/ (船)
seat /siːt/ (座位) vs. sit /sɪt/ (坐)
food /fuːd/ (食物) vs. foot /fʊt/ (脚)
cart /kɑːt/ (手推车) vs. cut /kʌt/ (切)


### 1.1 前元音

在英语中，主要有以下四个前元音：

1. **/iː/** (长元音)    
    - **发音**：嘴角向两边尽量拉开，像微笑一样，发音较长。
    - **示例**：`see` (看见), `sheep` (绵羊)
    
2. **/ɪ/** (短元音)    
    - **发音**：口型和舌位比 /iː/ 稍低、稍放松，发音短促。
    - **示例**：`sit` (坐), `big` (大的)
    
3. **/e/** (短元音)    
    - **发音**：舌尖抵下齿，舌前部稍抬起，嘴形扁平，上下齿间可容纳一个食指的宽度。
    - **示例**：`pen` (钢笔), `bed` (床)
    
4. **/æ/** (短元音)    
    - **发音**：舌尖抵下齿，舌前部降到最低，嘴巴张大，呈扁平状，上下齿间可容纳食指和中指。
    - **示例**：`cat` (猫), `hat` (帽子)
### 1.2 中元音

音色：发出的声音听起来比较松弛、模糊，是英语中最常见的元音类型之一。

在英语中，主要有以下三个中元音：

**/ɜː/** (长元音)
- 发音：舌身平放，舌中部稍稍抬高，嘴形扁平，上下齿微开。发音时声带振动，声音较长。
- 示例：girl (女孩), work (工作)

**/ə/** (短元音)
- 发音：这是英语中最常见的弱读元音，也称为“schwa”音。发音时口腔和舌头完全放松，发出一个非常短促、模糊的音。它通常出现在非重读音节中。
- 示例：ago (在...之前), teacher (老师)

**/ʌ/** (短元音)
- 发音：嘴唇微微张开，舌尖轻触下齿，舌后部稍稍抬起。发音短促有力。
- 示例：cup (杯子), come (来)

### 1.3 后元音

音色：发出的声音听起来比较厚重、浑厚。

在英语中，主要有以下五个后元音：

**/ɑː/** (长元音)
- 发音：口张大，舌身平放后缩，舌尖离开下齿。这是一个不圆唇的元音。
- 示例：car (汽车), father (父亲)

**/ɔː/** (长元音)
- 发音：双唇收圆并向前突出，舌后部抬起。发音较长。
- 示例：door (门), horse (马)

**/uː/** (长元音)
- 发音：双唇收圆并向前突出，形成一个小孔，舌后部抬至最高位。发音较长。
- 示例：blue (蓝色), zoo (动物园)

**/ʊ/** (短元音)
- 发音：双唇略微收圆并向前突出，但不如 /uː/ 紧张，舌后部抬起。发音短促。
- 示例：book (书), good (好的)

**/ɒ/** (短元音)
- 发音：双唇略微收圆，嘴巴张开，舌身后缩。发音短促。这个音在英式英语中很常见。
- 示例：hot (热的), dog (狗)
## 2. 双元音 8个 (Diphthongs)

发音时从一个元音**滑动**到另一个元音，口型和舌位有明显变化。英语共有**8个**双元音。

### **1. 合口双元音 (Closing Diphthongs)**
由舌位较低滑向较高，即嘴巴从较开滑向较闭。

| 音标                | 滑动方向         | 例词        |
| ----------------- | ------------ | --------- |
| /eɪ/              | 从 /e/ 滑向 /ɪ/ | day /deɪ/ |
| /aɪ/              | 从 /a/ 滑向 /ɪ/ | my /maɪ/  |
| /ɔɪ/              | 从 /ɔ/ 滑向 /ɪ/ | boy /bɔɪ/ |
| /aʊ/              | 从 /a/ 滑向 /ʊ/ | now /naʊ/ |
| /əʊ/ (英) /oʊ/ (美) | 从 /ə/ 滑向 /ʊ/ | go /ɡəʊ/  |

### **2. 集中双元音 (Centering Diphthongs)**
滑动向中元音 /ə/。

| 音标   | 滑动方向         | 例词          |
| ---- | ------------ | ----------- |
| /ɪə/ | 从 /ɪ/ 滑向 /ə/ | near /nɪə/  |
| /eə/ | 从 /e/ 滑向 /ə/ | hair /heə/  |
| /ʊə/ | 从 /ʊ/ 滑向 /ə/ | pure /pjʊə/ |


# 二. **辅音 (28个)**：


根据发音时气流受阻和释放方式的不同，辅音可以分为以下几类：

#### 1. 爆破音 (Plosives)

发音时，气流在口腔中完全受阻，然后突然释放，产生爆破效果。

- **清辅音 (声带不振动):** `/p/` (pen), `/t/` (top), `/k/` (cat)
- **浊辅音 (声带振动):** `/b/` (bad), `/d/` (dog), `/ɡ/` (go)

#### 2. 摩擦音 (Fricatives)

发音时，气流通过狭窄的通道产生摩擦而发声。

- **清辅音:** `/f/` (fun), `/θ/` (think), `/s/` (see), `/ʃ/` (she), `/h/` (hat)
- **浊辅音:** `/v/` (very), `/ð/` (this), `/z/` (zoo), `/ʒ/` (vision)

#### 3. 塞擦音 (Affricates)

由一个爆破音和一个摩擦音结合而成，先爆破后摩擦，形成一个音。

- **清辅音:** `/tʃ/` (chair), `/tr/` (tree), `/ts/` (cats)
- **浊辅音:** `/dʒ/` (judge), `/dr/` (dress), `/dz/` (beds)

#### 4. 鼻音 (Nasals)

发音时，口腔通道被堵住，气流从鼻腔通过。

- `/m/` (man), `/n/` (nice), `/ŋ/` (sing)

#### 5. 边音 (Lateral Approximant)

发音时，舌尖抵住上齿龈，气流从舌头两侧通过。

- `/l/` (let)

#### 6. 半元音 (Semi-vowels)

发音特点介于元音和辅音之间，气流受到的阻碍很小。

- `/w/` (we), `/j/` (yes)
