
# 1. **元音 (20个)**
声音响亮，气流不受阻碍，是单词发音的核心。
    
    - **单元音 (12个)**：根据舌头位置又分为：
        
        - **前元音**：/i:/, /ɪ/, /e/, /æ/
            
        - **中元音**：/ɜ:/, /ə/, /ʌ/
            
        - **后元音**：/u:/, /ʊ/, /ɔ:/, /ɒ/, /ɑ:/
            
    - **双元音 (8个)**：由两个单元音组成，发音时从第一个音滑向第二个音。
        
        - /eɪ/, /aɪ/, /ɔɪ/, /əʊ/, /aʊ/, /ɪə/, /eə/, /ʊə/


# 2. **辅音 (28个)**：
2. 气流在口腔或鼻腔受到阻碍而形成的音。
    
    - **按发音方式分类**：
        
        - **爆破音**：/p/, /b/, /t/, /d/, /k/, /g/
            
        - **摩擦音**：/f/, /v/, /θ/, /ð/, /s/, /z/, /ʃ/, /ʒ/, /h/, /r/
            
        - **破擦音**：/tʃ/, /dʒ/, /tr/, /dr/, /ts/, /dz/
            
        - **鼻音**：/m/, /n/, /ŋ/
            
        - **舌边音**：/l/
            
        - **半元音**：/j/, /w/
