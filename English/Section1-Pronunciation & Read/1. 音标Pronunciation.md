
# 1. **元音 (20个)**

声音响亮，气流不受阻碍，是单词发音的核心。

##  一、单元音 12 个 (Pure Vowels / Monophthongs)

|         | 前元音 (舌位靠前)   | 中元音 (舌位居中) | 后元音  (舌位靠后)      |
| ------- | ------------ | ---------- | ---------------- |
| **长元音** | /iː/         | /ɜ:/       | /u:/, /ɔ:/, /ɑ:/ |
| **短元音** | /ɪ/，/e/， /æ/ | /ə/, /ʌ/   | /ʊ/,/ɒ/          |


## 二、双元音 8个 (Diphthongs)

发音时从一个元音**滑动**到另一个元音，口型和舌位有明显变化。英语共有**8个**双元音。

**1. 合口双元音 (Closing Diphthongs)**：由舌位较低滑向较高，即嘴巴从较开滑向较闭。

| 音标                | 滑动方向         | 例词        |
| ----------------- | ------------ | --------- |
| /eɪ/              | 从 /e/ 滑向 /ɪ/ | day /deɪ/ |
| /aɪ/              | 从 /a/ 滑向 /ɪ/ | my /maɪ/  |
| /ɔɪ/              | 从 /ɔ/ 滑向 /ɪ/ | boy /bɔɪ/ |
| /aʊ/              | 从 /a/ 滑向 /ʊ/ | now /naʊ/ |
| /əʊ/ (英) /oʊ/ (美) | 从 /ə/ 滑向 /ʊ/ | go /ɡəʊ/  |

**2. 集中双元音 (Centering Diphthongs)**：滑动向中元音 /ə/。

| 音标   | 滑动方向         | 例词          |
| ---- | ------------ | ----------- |
| /ɪə/ | 从 /ɪ/ 滑向 /ə/ | near /nɪə/  |
| /eə/ | 从 /e/ 滑向 /ə/ | hair /heə/  |
| /ʊə/ | 从 /ʊ/ 滑向 /ə/ | pure /pjʊə/ |


# 2. **辅音 (28个)**：

 气流在口腔或鼻腔受到阻碍而形成的音。
    
    - **按发音方式分类**：
        
        - **爆破音**：/p/, /b/, /t/, /d/, /k/, /g/
            
        - **摩擦音**：/f/, /v/, /θ/, /ð/, /s/, /z/, /ʃ/, /ʒ/, /h/, /r/
            
        - **破擦音**：/tʃ/, /dʒ/, /tr/, /dr/, /ts/, /dz/
            
        - **鼻音**：/m/, /n/, /ŋ/
            
        - **舌边音**：/l/
            
        - **半元音**：/j/, /w/
