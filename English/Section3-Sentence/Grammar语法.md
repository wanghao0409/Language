### 动词是划分句型的根本


| 序号  | 句型结构                         | 示例                                                                      |
| --- | ---------------------------- | ----------------------------------------------------------------------- |
| 1   | 主语 + **不及物动词**               | *He **runs**. / She **smiles**. *                                       |
| 2   | 主语 + **单及物动词** + 宾语          | _I **love** English. / She **bought** a car._                           |
| 3   | 主语 + **双及物动词** + 间接宾语 + 直接宾语 | _He **gave** **me** a book._  <br>_She **told** **us** a story._        |
| 4   | 主语 + **复杂及物动词** + 宾语 + 宾语补足语 | *They **made** **him** **happy**.  <br>_I **saw** **her** **leaving**._ |
| 5   | 主语 + **系动词** + 主语补足语（表语）     | _She **is** **a teacher**. / It **became** **cold**._                   |
|     |                              |                                                                         |
